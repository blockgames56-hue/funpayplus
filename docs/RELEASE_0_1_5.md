# FunPay Plus 0.1.5

## Вход

После выбора «На этом компьютере» приложение открывается без ручного ключа.
Для VPS нужен только адрес установленной панели. Браузер и desktop получают
подписанную сессию автоматически; постоянный внутренний секрет сервера клиенту
не передаётся. Старое поле ключа и подсказки с access.key удалены. Просроченная
сессия обновляется автоматически. Сохранённые старые ключи удаляются из клиента.
Выбор VPS не запускает локальную автоматизацию.

Вход в публичную панель теперь открыт без пароля. Для личного доступа используйте
SSH-туннель или собственное ограничение доступа на reverse proxy. Подключение
аккаунта FunPay по golden_key сохраняется: это отдельная авторизация магазина.
На существующем VPS требуется обновление серверной части до 0.1.5.

## Motion design

Подключён lottie-web, используется лёгкий SVG-плеер без expressions. Две авторские
Lottie-анимации включены в приложение: орбита со спутниками и пульсирующий сигнал.
Анимации не требуют внешних сервисов, ключей или интернета после загрузки приложения.
Обновлены экран выбора режима, загрузка, пустые состояния, главная и каталог плагинов.
Добавлены цветные свечения, мягкие появления карточек и окон, упругие переключатели,
подсветка навигации, отклик кнопок и PNG-логотипов при наведении.

Анимации следуют выбранной теме, останавливаются вне экрана и в скрытой вкладке,
выключаются настройкой интерфейса и системным prefers-reduced-motion — в том числе
при изменении системной настройки без перезагрузки. При недоступности плеера
остаётся статичная SVG-заглушка.

Визуальные ориентиры: [Linear](https://linear.app/), [Raycast](https://www.raycast.com/),
[LottieFiles](https://lottiefiles.com/state-machines). Собственные SVG-анимации
находятся в apps/web/src/assets/animations. Документация:
[lottie-web](https://github.com/airbnb/lottie-web/wiki/loadAnimation-options),
[Motion accessibility](https://motion.dev/docs/react-accessibility).

## Проверки

Изолированные ASGI-проверки входа без ключа, cookie/подписанной сессии, проверки
Origin, WebSocket-ticket, просроченных и повреждённых сессий; регрессия API и запуска.
Браузерные сценарии проверяют локальный и VPS-режимы без ручного ключа, отсутствие
локального запуска в VPS-режиме, проигрывание Lottie, анимации карточек/переключателей,
геометрию диалогов, светлую тему, мобильную ширину и отключение движения.
Реальные сообщения и покупки не выполняются; живой VPS не предоставлен.

С учётом неизменённых модулей регрессии подтверждены 468 Python-проверок в 33
модулях. Повторно выполнены затронутые проверки API, входа/VPS, запуска, ошибок
и установки; также 2 JS-теста, отдельный сценарий server-connection и TypeScript/Vite.
