# Выбор и массовые действия с лотами

Страница лотов вынесена в отдельный лениво загружаемый `apps/web/src/lots-page.tsx`. Reshaped загружается вместе с ней, его тема slate/dark ограничена страницей. Общий интерфейс приложения сохраняет свою тему.

Компоненты: `apps/web/src/components/ui/reshaped-checkbox.tsx`, пример — `demo.tsx`. Стили приложения — `apps/web/src/styles.css`. TypeScript и Tailwind v4 уже установлены; для структуры shadcn добавлены `components.json`, `src/lib/utils.ts`, алиас `@/*` в TypeScript и Vite. Папка `src/components/ui` является общей точкой для компонентов и генератора shadcn, чтобы повторные интеграции не создавали несовместимые копии. Графические ассеты для Checkbox не требуются.

Выбор управляется Zustand. Можно выбрать конкретные строки или все найденные поиском и фильтрами категории/статуса. Скрытые фильтром выбранные строки явно подсчитываются; подтверждение удаления перечисляет все затронутые предложения. При смене аккаунта выбор очищается. Чекбоксы поддерживают клавиатуру, промежуточное состояние и увеличенную область нажатия.

Цена, активность и удаление применяются только к выбранным ID. Поднятие FunPay выполняет для категории целиком; предупреждение находится рядом с действиями, запрос категории не дублируется для каждого выбранного лота.

Массовые обновления используют свежую форму, актуальный CSRF, AJAX-заголовок и проверку подтверждения вместо прежнего отдельного пути сохранения без заголовка. Поддерживаются явные подтверждения `done=true` и ответ без `done` с `error=false`. Пустой ответ или HTML не считаются успехом. При ошибке авторизации, проверке браузера или неподтверждённом формате пакет останавливается без повторной отправки изменений.

Удаление требует отдельного подтверждения с перечнем предложений. Локальная запись удаляется только после подтверждения FunPay. Привязанные к плагинам лоты защищены: сначала необходимо снять привязку. Ошибки показываются в отчёте по лотам, одинаковые сообщения группируются. Успешные строки снимаются с выбора, данные обновляются и при частичном сбое.

Проверка: полный backend suite — 205 passed; дополнительные целевые проверки после расширения формата подтверждения; Playwright проверяет выбор мышью/клавиатурой, фильтры, промежуточное состояние, точные ID удаления, отмену подтверждения, частичное изменение цены, обновление данных, скрытие/активацию, поднятие, автоподнятие, смену аккаунта и ширины 1440/390 px. Реальный редактор одного пользовательского лота проверен только чтением: поля цены и активности доступны. Изменение и удаление реальных предложений во время проверки не выполнялись.

Компонент: [Reshaped Checkbox](https://www.reshaped.so/docs/components/checkbox). Формат запросов сопоставлен с [исходником FunPayAPI](https://github.com/MorikTV/FunPayAPI/blob/main/account.py).
