# Telegram: бот и Mini App

Одна установка FunPay Plus использует одного Telegram-бота для своих аккаунтов.
Бот, Mini App и настольный клиент обращаются к одной серверной базе. Отдельного
копирования настроек в Telegram нет: изменение сразу сохраняется в установке,
к которой вы подключились. Токен хранится зашифрованным в этой базе.

## Подключение

1. Установите приложение на VPS либо запустите его на Windows. На Linux VPS
   устанавливается серверная версия проекта; EXE нужен для Windows-клиента.
2. Если работаете с VPS, сначала выберите в клиенте «На своём VPS» и подключитесь
   к нему. Иначе настройки будут сохранены на текущем компьютере.
3. Создайте бота командой `/newbot` у [@BotFather](https://t.me/BotFather).
4. Откройте «Настройки → Telegram», вставьте токен. Он проверяется и сохраняется
   автоматически. Нажмите «Подключить мой Telegram» и откройте полученную ссылку.
5. Нажмите «Запустить» в Telegram. Одноразовая ссылка действует 10 минут.
   Chat ID заполнится автоматически; доступ будет только у привязанного владельца.
6. Для уведомлений раскройте «Уведомления и ответы», включите их и выберите события.
   Ответ на уведомление о сообщении покупателя отправляется в соответствующий чат.

На VPS фоновые задачи и бот продолжают работать после закрытия EXE, браузера и SSH.
На локальном ПК они работают, пока запущен backend приложения/консольный процесс.
Закрытый или выключенный локальный компьютер не может обслуживать Telegram.
Один токен нельзя одновременно опрашивать на ПК и VPS: остановите старую установку
после переноса. Удаление webhook при привязке переключает бота на polling этой установки.

## Mini App

Нужен доступный телефону HTTPS-адрес панели с действительным сертификатом.
Это требование [Telegram WebAppInfo](https://core.telegram.org/bots/api#webappinfo).
Обычный localhost, SSH-туннель на домашнем ПК и HTTP-адрес VPS для Mini App не подходят.
Без HTTPS-адреса работает меню бота с кнопками.

Для установки с HTTPS направьте домен на сервер, откройте TCP 80/443 и выполните
под root, заменив `panel.example.com` своим доменом:

```bash
curl -fsSL https://raw.githubusercontent.com/blockgames56-hue/funpayplus/main/install.sh | bash -s -- --repo https://github.com/blockgames56-hue/funpayplus.git --domain panel.example.com
```

[Установка и обновление существующего VPS](INSTALL_COMMANDS.md).
Сначала перенесите имеющиеся данные, если новая установка пустая:
[перенос с Windows](SERVER.md#перенос-текущих-данных-с-windows-одной-командой).
Не оставляйте две активные копии одного магазина и Telegram-токена.

Укажите `https://panel.example.com` в поле «HTTPS-адрес панели для Mini App».
Адрес преобразуется в `/telegram`, кнопка меню применяется автоматически,
включая повторную попытку после восстановления сети. Откройте бота и нажмите
«Открыть панель». Дополнительные настройки BotFather для кнопки меню не нужны.
Если редактируете существующий HTTPS deployment вручную, согласуйте PUBLIC_ORIGIN,
ALLOWED_ORIGINS и сертификат с адресом; обновите frontend вместе с backend.

Mini App содержит компактный главный экран, нижнюю навигацию и существующие
страницы приложения: аккаунты, автоматизацию, переписку, редактирование/действия
с лотами, плагины и их настройки, KOSell Rent, автоответы, автовыдачу, бонусы,
финансы, прокси, чёрный список и журнал. Дизайн и анимации доступны в свёрнутом
разделе внешнего вида. Автосохранение использует те же API, что и EXE.

## Меню бота без домена

| Команда | Действия |
| --- | --- |
| `/menu`, `/start` | Кнопки разделов и Mini App при наличии HTTPS |
| `/status` | Активные аккаунты, лоты, оплаченные заказы и непрочитанные сообщения |
| `/accounts` | Список и запуск/остановка аккаунта с подтверждением |
| `/lots` | Просмотр, поднятие, активация, скрытие и удаление с подтверждением |
| `/chats` | Последние сообщения и ответ покупателю |
| `/plugins` | Состояние и включение/выключение плагинов с подтверждением |
| `/settings` | Переключение уведомлений и переход к расширенным настройкам |
| `/logs` | Последние события приложения |

Расширенные формы и шаблоны редактируются в Mini App или приложении. Отправка
текста покупателю требует ответа на специальное сообщение бота. Действия с лотами
и аккаунтами выполняются существующим API; ограничения FunPay продолжают действовать.
Кнопки подтверждения одноразовые и действуют две минуты. При неопределённом результате
проверьте приложение перед повтором: потенциально опасные операции не повторяются
автоматически после сбоя. Неподтверждённые кнопки после перезапуска нужно создать заново.

## Доступ

Mini App проверяет подпись initData по [документации Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app),
время запуска и Telegram ID владельца. Сессия действует до 24 часов; при истечении
откройте Mini App заново. Смена владельца, отключение управления или изменение токена
отзывают прежние Telegram-сессии. При смене бота из авторизованной панели текущее
устройство получает обновлённую сессию, а ID владельца сохраняется.

После настройки публичной Mini App удалённый вход без подтверждения закрывается.
EXE сможет подключиться через ссылку «Подтвердить вход в Telegram»: бот попросит
разрешить ваше новое устройство, клиент продолжит подключение автоматически.
Ссылка входа действует пять минут. Подтверждайте только запрос, который создали сами.
После отключения бота защита публичного входа остаётся; восстановить управление
можно из ранее авторизованного административного клиента или локально на сервере.
Вводить постоянный ключ приложения пользователю не требуется.

Кнопка «Отключить доступ» отзывает Telegram-управление, но не удаляет магазин и
настройки уведомлений. Полностью остановить обращения к Telegram можно отключением
управления и уведомлений. BotFather позволяет отозвать скомпрометированный токен.

## Проверка и архитектура

Долгий polling выполняется отдельной задачей и HTTP-соединением, не удерживает
очередь отправки сообщений. Offset сохраняется отдельно для каждого токена;
привязки сообщений различают ботов, поэтому совпавшие номера уведомлений другого
бота не направляют ответ старому покупателю. Все сервисы завершаются вместе с backend.
В Docker остаётся один worker и постоянное хранилище; отдельного Telegram-контейнера
или ручного запуска бота не требуется.

Для сверки подхода просмотрен [Telegram-код Cardinal](https://github.com/sidor0912/FunPayCardinal/blob/main/tg_bot/bot.py):
проверка пользователей и polling. Реализация FunPay Plus собственная, с одноразовой
привязкой вместо отдельного ручного пароля. Исходник поставщика KOSell Rent не менялся.

Проверки выполняются на временных БД с подменой Telegram/FunPay и в браузере с
подписанными тестовыми initData. Настоящий BotFather-токен, HTTPS-домен и VPS для
живой проверки пользователем ещё не подключены; доставка Telegram и сертификат
конкретного сервера требуют проверки после настройки.
