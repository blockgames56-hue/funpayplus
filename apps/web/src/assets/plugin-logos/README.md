# PNG-логотипы плагинов

Положите свои PNG-файлы в **эту папку**. Названия должны совпадать с таблицей:

| Плагин в приложении | Имя файла |
|---|---|
| KOSell Rent | `kosell-rent.png` |
| Auto Steam Rent | `steam-rent.png` |
| Steam Guard · Коды | `offline.png` |
| Email Code Fetcher | `email-code.png` |
| AutoTicket · Поддержка | `support-tickets.png` |

Рекомендуется квадратный PNG размером **256×256 или 512×512**, можно с прозрачным
фоном. Логотип вписывается в квадрат без обрезки. Названия — маленькими английскими
буквами, с дефисами, без пробелов. Расширение `.png` предпочтительно; `.PNG` также
поддерживается. Не сохраняйте два варианта одного логотипа с разным регистром расширения.

Если файла пока нет или он повреждён, отображается цветная заглушка с эмодзи.
Пустые или фиктивные PNG создавать не нужно. Иконки внутри разделов настроек остаются
эмодзи; ваш PNG используется в карточке плагина и рядом с его названием на странице.

Код редактировать не нужно: файлы подхватываются сборщиком автоматически.

- В режиме разработки `npm run dev` добавленные файлы подхватываются автоматически;
  если страница уже открыта, обновите её.
- Для собранного приложения или VPS нужно заново собрать/обновить приложение после
  добавления изображений. Простое копирование файлов в исходники не меняет уже
  установленный Windows EXE.

Сборка веб-интерфейса из корня проекта: `npm run build`.
Сборка Windows-установщика: `powershell -ExecutionPolicy Bypass -File deploy/build-desktop.ps1`.
